# AGENTS.md

This repo holds byteCare's brand as a Quarto brand: `_brand.yml` in the [brand.yml](https://posit-dev.github.io/brand-yml/) format, plus logo assets.

## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues (bytecaretech/bytecare-brand) via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default five-role vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
